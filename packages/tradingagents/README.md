# tradingagents

Multi-agent LLM financial trading framework. The canonical documentation lives
in the repository root `README.md`; this package is one member of the
`trading-agents` uv workspace.

## Development

```bash
uv sync                       # from the repo root (installs all workspace members)
uv run pytest -m unit         # run this package's fast tests
uv run tradingagents          # CLI console script
```
